# Requisitos del Sistema

## Requisitos funcionales

- **RF01:** El sistema debe permitir registrar mascotas junto con los datos de su propietario (nombre, especie, raza, edad, contacto).
- **RF02:** El sistema debe permitir agendar una cita veterinaria seleccionando fecha, hora y motivo de la consulta.
- **RF03:** El sistema debe permitir consultar y actualizar el historial clínico de cada mascota (diagnósticos, tratamientos y vacunas aplicadas).

## Requisitos no funcionales

- **RNF01:** La interfaz del sistema debe ser responsive, adaptándose correctamente a dispositivos móviles y de escritorio.
- **RNF02:** El sistema debe responder a las solicitudes del usuario en un tiempo menor a 2 segundos bajo condiciones normales de uso.
- **RF04:** El sistema debe permitir cancelar o reprogramar una cita ya agendada.
