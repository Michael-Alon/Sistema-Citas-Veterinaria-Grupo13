# Sistema de Citas para Veterinaria

## Descripción
Sistema web para la gestión de citas de una clínica veterinaria. Permite a los propietarios de mascotas registrar a sus animales, agendar citas de manera organizada y llevar un control del historial clínico de cada mascota, evitando la superposición de horarios y la pérdida de información en registros manuales o en papel.

## Objetivo
Facilitar la administración de citas veterinarias mediante una plataforma que permita registrar mascotas, agendar consultas, gestionar el historial clínico y mantener informados a los propietarios sobre sus próximas citas.
